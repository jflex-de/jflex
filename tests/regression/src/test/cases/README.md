# Test suite

The hand-written `.test` cases, run by `TestsuiteTest`. The format is described in
[the tests README](../../../../README.md). The cases for the Unicode properties are in the
`tests/unicode` module, most of them generated from the Unicode Character Database.

The rest of the regression tests is in `src/test/java/de/jflex/testcase`.
