# JFlex regression tests

The hand-written end-to-end tests of JFlex: scanner specs with their expected output, as
JUnit tests in `src/test/java/de/jflex/testcase` (one directory per case) and as `.test`
cases in `src/test/cases`, see [the tests README](../README.md).

## Run the tests

The tests need `jflex-maven-plugin` from the same build, so install that first and use
`install`, not `test`:

    scripts/mvn-install-fastbuild.sh jflex-maven-plugin
    ./mvnw -pl tests/framework,tests/regression install

To run only a single test, add for instance

    -Dtest=ActionPipeEofTest -Dsurefire.failIfNoSpecifiedTests=false

The tests run with `target/work` as their working directory, which is deleted and
filled with a fresh copy of the test data (specs, inputs, goldens) on each build.
The purpose is to keep files generated by tests out of the source tree. Builds are
still incremental from there. This means the tests should be run through Maven.
Running manually via IDE will skip the copy step.
