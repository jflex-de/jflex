# JFlex test suite

## Run the test suite

The tests run in the Maven module `javatests` ([pom.xml](../../../../pom.xml)).
It uses `jflex-maven-plugin` from the same build, so install that first and use
`install`, not `test`:

    scripts/mvn-install-fastbuild.sh jflex-maven-plugin
    ./mvnw -pl java,javatests install

To run only a single test, add for instance

    -Dtest=ActionPipeEofTest -Dsurefire.failIfNoSpecifiedTests=false`.

The tests run with `javatests/target/javatests-work` as their working directory,
which is deleted and filled with a fresh copy of the test data (specs, inputs,
goldens) on each build. The purpose is to keep files generated by tests out of
the source tree. Builds are still incremental from there. This means the tests
should be run through Maven. Running manually via IDE will skip the copy step.
